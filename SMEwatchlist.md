**Hard rules**
- Max **2 Live** tickets.
- Size **0.3–0.75%**. Circuit / UC week = no add.
- Work FV must sit **≥25%** above add, or it is Cap.
- 2-q miss on book / tonnes / cash = Kill.
- Theme must be Defence · Power · Tech-mfg · Biotech / energy materials.
- Flow (Vihaan / SPJ) is a cue. It does not promote a name onto Core.

4. Can exit half the ticket in one session without an 8% hole.
